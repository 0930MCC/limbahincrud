# Gallery Images

Place your JPG, PNG, or WebP images in this folder. They will automatically appear in the Galeri page on the website.

## Filename Convention

- `Medis - Rumah Sakit.jpg` → Category: Medis, Title: "Rumah Sakit"
- `Industri - Pabrik Kimia.jpg` → Category: Industri, Title: "Pabrik Kimia"
- `Armada - Truk Pengangkut.jpg` → Category: Armada, Title: "Truk Pengangkut"
- `Foto Dokumentasi.jpg` → Category: Dokumentasi (default), Title: "Foto Dokumentasi"

## Supported Categories
Medis, Industri, Komersil, Produk & Bahan, Armada, Tim & Operasional, Dokumentasi

## How to Add
1. Copy your image file to this folder (`src/assets/gallery/`)
2. Name the file using the convention above (e.g., `Medis - Limbah RS.jpg`)
3. The image will automatically appear on the Galeri page after the site rebuildsr
